# Migration Truth Audit

Date: 2026-04-13

## Current migration truth

### What is materially real
- source intake exists in setup
- migration guidance persists through setup and onboarding
- guest import now has better header matching, review cues, household guardrails, and post-import summary truth
- story/event recovery helpers exist
- FAQ migration shaping exists
- registry-link carryover helpers exist
- setup/dashboard/public surfaces now contain migration proof language

### What is still partial
- migration is still guided, not automated
- no one-click source-platform content import exists
- story/event/FAQ/registry recovery is helper-based, not a full platform parser
- migration review is stronger, but still relies on human verification before publish

### Safe claim
DayOf supports a calmer guided migration path from other wedding platforms.

### Unsafe claim
DayOf fully migrates another wedding platform automatically.

## Close call
Migration work is now materially real enough to claim as guided switching support. It is not yet a fully automated migration engine, and product language should stay honest about that.
