# Save-the-date workflow audit

Date: 2026-04-13

## What exists now
- save-the-date message preset exists in dashboard Messages
- guest communication lifecycle includes save-the-date as a stage
- onboarding/status model understands invitation timing context

## What is missing
- no dedicated save-the-date workflow surface
- no clear send/save-the-date tracking status distinct from invitations/reminders
- no obvious recipient segmentation specifically for save-the-dates
- feels like a template/preset, not a first-class workflow

## Honest conclusion
Save-the-dates are **partially real**.
The content layer exists, but the workflow layer is weak.

## Best v1 completion target
Do not overbuild.
A real save-the-date v1 should have:
- dedicated quick action
- default recipient segment
- scheduled send support
- status visibility

## Next implementation target
- add a dedicated save-the-date send action in Messages or Guests
- track it as a distinct communication action
