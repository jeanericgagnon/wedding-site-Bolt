# AI Impact Gap Scorer Plan

Shift the planner from slot-based missing-info logic to impact-based site-improvement logic.

## Core question
Instead of asking:
- what information is missing?

Ask:
- what missing information would most improve the final site?

## New gap categories
### 1. event completeness
Questions in this category help:
- schedule
- travel
- FAQ
- RSVP event context

Example ask:
- What events are happening across the weekend, even if rough?

### 2. guest clarity
Questions in this category help:
- homepage tone
- FAQ usefulness
- travel guidance
- overall “thoughtful” feel

Example asks:
- What should guests expect from the weekend overall?
- Is there anything guests might be confused about or need extra guidance on?
- Are most guests traveling in, or are they local?

### 3. emotional depth
Questions in this category help:
- hero warmth
- story warmth
- site personality

Example ask:
- What’s one thing that feels very “you two” that you’d want reflected on the site?

### 4. decision clarity
Questions in this category help:
- registry
- guest guidance
- meal / plus-one clarity when relevant

Example ask:
- Do you want to guide guests at all on gifts or keep it open?

### 5. location meaning
Questions in this category help:
- hero
- story framing
- travel context

Example ask:
- Why did you pick this location?

## Intake upgrades
High-value additions to the initial intake:
- guest expectation anchor
- travel reality
- confusion guidance
- lightweight tone preference

These should beat deep story questions in importance.

## Planner behavior target
1. collect intake
2. derive local snapshot
3. score impact gaps
4. ask top 1–2 gaps only
5. allow skip / unresolved / TBD where appropriate

## Scoring dimensions
Each gap should be scored by:
- section impact breadth
- urgency
- knowability now
- token efficiency
- whether the answer reduces confusion or improves emotional clarity

## Important rule
Do not ask a question just because data is absent.
Only ask it if the answer would materially improve the final site.

## Why this is better
This avoids:
- rigid slot thinking
- random story overuse
- over-asking event cleanup
- wasting tokens on low-value detail collection

And it pushes the system toward:
- better homepage tone
- better FAQ usefulness
- better guest guidance
- better emotional warmth
- better overall site coherence
