# Dayof Brand Voice

Created: 2026-04-01

## Core idea

Dayof.Love should feel:
- beautiful without being precious
- organized without being cold
- calm, opinionated, refined, and useful

The voice should make people feel:
- this looks good
- this is organized
- this won’t fail when it matters

## What Dayof is
- clear
- composed
- tasteful
- dependable
- slightly opinionated
- quietly premium
- anti-chaos

## What Dayof is not
- whimsical
- gushy
- fake luxury
- startup-hypey
- cutesy
- generic wedding copy
- overly sentimental
- loud

## Voice sliders
- Warmth: 6/10

- Practicality: 9/10

## Writing rules
- Say what it does first.
- Never hide the function behind brand language.
- Understate.
- If it can be simpler, make it simpler.
- Name the mess: scattered tools, RSVP chasing, guest confusion, last-minute updates, generic templates.
- Sound calm under pressure.
- Be opinionated, but not aggressive.

## Good patterns
- Do X without Y
- Everything in one place
- Looks like X, works like Y
- Not this. This.
- Short contrast

## Internal one-line summary

A wedding brand with taste, clarity, and zero chaos.

## Practical filter

If it sounds like invitation stationery, it is too soft.
If it sounds like enterprise software, it is too cold.
Dayof should live between those two.
