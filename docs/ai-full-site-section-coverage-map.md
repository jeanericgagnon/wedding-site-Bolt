# AI full-site section coverage map

## Purpose
Define which customer-facing sections should eventually receive meaningful AI-generated copy, and distinguish between:
- already covered
- partially covered
- not yet covered

This is the planning map for moving from a proven AI core to a true full-site copy engine.

## Status legend
- **covered** = AI generates meaningful copy and it lands in canonical builder/public paths
- **partial** = some title/framing coverage exists, but not enough to feel complete
- **none** = no meaningful AI copy contract yet

## What “full-site copy engine” means
To honestly call the AI copy engine complete, it should cover:

1. all major homepage sections with meaningful copy, not just titles
2. guest-facing helper sections with graceful intro/framing copy
3. canonical builder/public write path for every covered field
4. overwrite safety for all covered builder-owned text fields
5. quality evaluation across rich, medium, and sparse profiles
