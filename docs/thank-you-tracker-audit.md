# Thank-you tracker audit

Date: 2026-04-13

## Current real pieces
- `thank_you_sent_at` exists on guests
- Guests dashboard already supports:
  - thank-you-due filter
  - single guest mark-as-sent
  - mark all due as sent
  - thank-you due export CSV
- lifecycle helper already includes `Thank-you sent`

## What this means
A thank-you tracker is already more real than the roadmap suggests.

## What is still missing
- no dedicated standalone thank-you tracker surface
- no note/history per thank-you message
- no thank-you drafting/sending workflow tied directly to the tracker
- no stronger post-gift / post-attendance gratitude dashboard

## Honest conclusion
Thank-you tracking is **not missing**.
It already exists in practical operational form inside Guests.
The gap is mostly product framing / dedicated surface depth.

## Best truth label
- thank-you tracker = **done enough for v1**
- not a polished standalone gratitude workspace yet
